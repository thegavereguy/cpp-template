#### Instructions

##### Dependencies

The project requires basing compiling requirements, all the libraries used, if not found in the system, are fetched from the corresponding repositories.

```sh
# Fedora
sudo dnf install git gcc gcc-c++ ccache ninja-build cmake

# I'll add the rest later
```

The libraries used are Reflectcpp (CSV file parsing), spdlog (logging) and Catch2 (testing). The Arrow library, if not installed, is also compiled as it's required by Reflectcpp.

##### Creating the datasets

The three datasets, *training*, *validation* and *testing* are generated by the script 'resources/split_data.sh'. It takes random rows from the original set and puts them in on the three other files.
This script is 100% AI generated as i was too lazy do write bash myself, thus it suck and has to be reworked.

Usage:
```sh
sh ./split_data.sh <input.csv>  <% of rows for training> <% for validation> <% for testing>

# Example
sh ./split_data.sh ./cancer_data.csv  80 10 10
```

##### Building

As a starting point, I created a CMake present, you can start from that if you want to modify something.

```sh
cmake --preset Reselase -S . -B _build
cmake --build _build
```

##### Running

There's still a lot to improve here, but this does the job for now:

```sh
./build/apps/app ../resources/train.csv ../resources/val.csv ../resources/test.csv
```
